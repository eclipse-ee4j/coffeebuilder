## Development and pull requests

The active development branch is `develop`. Create pull requests against `develop`.

Use Java 21 and Maven to verify the complete reactor from the repository root before submitting a pull request:

```bash
mvn verify
```

Keep changes focused, include tests where appropriate, and ensure the build succeeds.

## Eclipse Contributor Agreement

To contribute to Eclipse Foundation projects, you must electronically sign the Eclipse Contributor Agreement (ECA).

- https://www.eclipse.org/legal/ECA.php

The ECA provides the Eclipse Foundation with a permanent record that you agree that each contribution will comply with the commitments documented in the Developer Certificate of Origin (DCO). An ECA associated with the email address in the author field of your Git commits fulfills the DCO requirement that you sign off on your contributions.
